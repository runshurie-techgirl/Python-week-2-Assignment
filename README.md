# Chapati Price Calculator 🫓

A simple interactive Python program that works out how much you pay for chapati. Built for the **Python Week 1 assignment**.

## What it does

1. Asks for the price of one chapati (in KES).
2. Asks how many chapati you want.
3. Calculates the total.
4. Prints a neat summary using an f-string.

## Example

```
Enter the price of one chapati (KES): 30
How many chapati do you want? 3
3 chapati at 30.00 each = 90.00 KES
```

## How to run it

1. Install [Python](https://www.python.org/downloads/) if you don't have it.
2. Download or clone this repository.
3. Open a terminal in the project folder and run:

```
python calculator.py
```

You can also open the folder in VS Code and click the Run (▶) button.

## Concepts practised

- `input()` to take user input (it always returns text)
- `float()` to convert the price to a decimal number
- `int()` to convert the quantity to a whole number
- Arithmetic: `total = price * quantity`
- f-strings with formatting (`:.2f` shows 2 decimal places)
